# LLM Radar Briefing

Short briefing on the current go-to open-source projects for running and serving large language models locally (inference engines, serving frameworks, local runtimes), cross-referenced against the starred-repository list on the HeziLiu GitHub account.

## Top picks

### 1. vLLM
- Purpose: High-throughput LLM inference and serving engine built around the PagedAttention algorithm.
- Latest release / maintenance: v0.30.0 (Sept 2026); actively maintained, with a strategic extensibility/innovation framework in progress.
- Already star it: No — not among the starred repositories.

### 2. Ollama
- Purpose: Easy local LLM runtime for pulling, running and serving models on your own hardware.
- Latest release / maintenance: 0.30.9 (Oct 2025); actively maintained with frequent version drops and architecture support.
- Already star it: No — not among the starred repositories.

### 3. llama.cpp
- Purpose: C/C++ inference runtime for LLMs and VLMs with minimal setup, running on wide hardware locally and in the cloud.
- Latest release / maintenance: Frequent releases under the ggml-org; the founding ggml.ai team joined Hugging Face in Feb 2026; actively maintained.
- Already star it: No — not among the starred repositories.

### 4. SGLang
- Purpose: High-performance serving framework for LLMs and multimodal models, with structured-output and multi-replica server support.
- Latest release / maintenance: Actively developed under the sgl-project org; multi-replica serving support landed; actively maintained.
- Already star it: No — not among the starred repositories.

### 5. LM Studio
- Purpose: Desktop GUI for running and serving local LLMs with chat, RAG and function calling.
- Latest release / maintenance: Regular releases; actively maintained and widely used for local LLM experimentation.
- Already star it: No — not among the starred repositories.
