# LLM Radar — Local LM Serving Briefing

A short briefing on the current go-to open-source projects for running and serving large language models on local hardware, cross-referenced against the author's starred GitHub repositories.

## Top picks

1. **llama.cpp** (ggml-org/llama.cpp) — C/C++ inference engine for running GGUF-quantized LLMs on CPU, CUDA, Vulkan, Metal and other backends. Latest releases in 2025 (e.g. v2025.03 / v2025.05); actively maintained under the ggml-org org. Already star it: No.
2. **vLLM** (vllm-project/vllm) — high-throughput, memory-efficient LLM inference and serving engine with PagedAttention. Latest 0.25.0 (Jul 2026 per Freedom.tech); milestone 0.20.2; actively maintained. Already star it: No.
3. **Ollama** (ollama/ollama) — easiest local LLM runtime with model auto-download and a REST API. Latest 0.34 (Sep 2026 per Freedom.tech; Termux rebuild from v0.33); actively maintained. Already star it: No.
4. **LM Studio** (lmstudio-ai/lms) — desktop GUI plus local OpenAI-compatible server for running open-weight models. Latest 0.3.30 (Oct 18, 2025); actively maintained. Already star it: No.
5. **SGLang** (sgl-project/sglang) — high-performance serving framework for LLMs and multimodal models with structured output. Actively maintained; Q1 2026 roadmap on an HTTP-serving plugin refactor; community-maintained cookbook (sgl-project/sgl-cookbook). Already star it: No.
